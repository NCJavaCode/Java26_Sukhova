# OOP22_Init

# Система управління кафе

## Про проєкт:
Розробка програмного забезпечення для автоматизації внутрішніх бізнес-процесів кафе. Система призначена для управління персоналом, ведення меню, обробки замовлень клієнтів та базового обліку інгредієнтів на складі.

## Мета проєкту:
Закріплення навичок програмування на мові Java. Практика проєктування архітектури програмного забезпечення.
